Quick start

Copy a request and run it against this local API.

Create a ticket
curl -X POST http://127.0.0.1:8000/tickets \
  -H 'Content-Type: application/json' \
  -d '{"userId":7,"id":42,"title":"Laptop will not start","completed":false}'
Replay safely
curl -X POST http://127.0.0.1:8000/tickets \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-42' \
  -d '{"userId":7,"id":42,"title":"Laptop will not start","completed":false}'
Start onboarding
curl -X POST http://127.0.0.1:8000/onboarding-requests \
  -H 'Content-Type: application/json' \
  -d '{"request_type":"onboarding","employee_name":"Jane Doe","employee_email":"jane@example.com","department":"Sales","requester_id":3}'
